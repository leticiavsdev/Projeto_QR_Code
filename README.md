# 📱 Gerador de QR Code

Um gerador de QR Code simples, moderno e responsivo desenvolvido com **HTML5, CSS3 e JavaScript**, utilizando a API pública do [QR Server](https://goqr.me) para a geração instantânea dos códigos.

## 🚀 Funcionalidades

- **Geração Instantânea:** Digite qualquer texto ou URL e gere um QR Code na hora.
- **Validação de Campo:** Caso o usuário tente gerar o código com o campo vazio, o input exibe uma animação visual de tremor (*shake effect*) alertando sobre o erro.
- **Efeito de Transição:** A caixa do QR Code surge suavemente na tela utilizando transições em CSS.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, posicionamento absoluto e animações personalizadas (`@keyframes`).
- **JavaScript (Vanilla):** Manipulação de DOM, tratamento de eventos e integração com API.
- **API QR Code:** [QRServer API](https://goqr.me) para renderização da imagem do código.
